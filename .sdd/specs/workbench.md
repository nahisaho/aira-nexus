## Design
React/Vite, Tailwind, existing Radix-based shadcn/ui and Lucide remain. A scope-keyed WorkspaceTabs owns ordered metadata and active value; its typed ref exposes openFile and an optional renderer hosts the research-services viewer keyed only by scope and file ID, never name or metadata object. A same-ID name update preserves the mounted viewer; inactive content unmounts and discards renderer-local state. Standalone consumers retain the unavailable placeholder. Fixed triggers are not draggable; close buttons are siblings, never nested buttons. Local drag source plus instance-scoped DataTransfer gates drops; reorder/cancel cannot change file identity. Radix navigation and explicit focus restoration retain accessibility.
Workspace-only tab wrappers paint trapezoidal backgrounds with non-interactive pseudo-elements, so triggers, sibling close buttons and focus indicators are not clipped. Shared Tabs primitives and tab state transitions remain unchanged. Remove the strip bottom margin and root flex gap, render the list without an inline baseline gap, and square only the view's top corners; keep existing view padding, content, bottom corners and scroll behavior.
A user-scope-keyed ResizableWorkspace uses bounded CSS grid tracks, two vertical ARIA separators, pointer capture and ResizeObserver; widths start at 260/264px with 8px handles. Left/Right moves a separator 10px (Shift:50), Home/End reach bounds, Escape/pointercancel/unfinished lost capture cancel; completed capture loss must not undo committed widths. Effective container width is at least the existing CSS minimum1024px. Widths survive project selection but reset on logout/identity change/remount. Existing verified identity, project UUIDs, request cancellation/errors and acknowledged preference application are unchanged.
Scrolling policy: signed-out has no pane groups; signed-in expanded has three focusable groups; collapsed-left has only center/right focusable. The signed-in shell is viewport-height flex, header/errors do not shrink, and the remaining-height grid contains independent native overflow-y:auto groups. Existing separator tracks, account/project state and file-preview overflow remain unchanged.
## Assumptions / risks
Confirmed order is AI chat, Notebook, then files. The original tab-only delivery remains independently usable; upload/storage/preview and their dependencies now belong exclusively to the approved research-services contract, not this shell contract. Closing removes only a view, never stored data; chat/Notebook execution remains unavailable. Tab/width state is page memory only, never local/server storage; reopen metadata uses a stable caller-supplied ID. Desktop minimum remains 1024px with horizontal scrolling below it; Japanese defaults and explicit English/Light/Dark remain. State/input/browser counterexamples are tested; real SSO, mobile optimization and future execution remain external, and mocked failures prove no live Entra connectivity. Spike: actual existing Radix wrappers support sibling close buttons, keyboard focus, native file-tab drag and captured pointer resizing in an isolated browser; first CommonJS-import setup failure is not passing evidence.
Scrollbars are vertical and browser-native, appearing only for overflow; short-content groups remain focusable. JSDOM cannot establish geometry, so actual browser wheel/keyboard/bottom, long/short, error-banner, collapse and narrow-width checks plus restored runtime CSS mutations complement the native focus regression. The isolated candidate and its native receipt are not Root qualification.
