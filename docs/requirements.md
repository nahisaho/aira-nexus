# 確定要件と実装順の案内

研究支援サービスの依頼者・開発者向けに、合意内容と実装状況の読み方を示す。
更新: 2026-11-12。これは説明資料であり、実装契約の正本は [.sdd/specs/](../.sdd/specs/)。

## 合意した利用像

組織内の研究者・分析担当者が、文献調査、Python/R分析、レポート作成を行う。
初期版はEntra IDの単一テナント、プロジェクトは個人専用。共有・招待は対象外。
画面は左にプロジェクト管理、中央にチャット／ファイルビューア／Notebookのタブ、右にファイルエクスプローラー。
Web UIはReact/TypeScript/Vite、Tailwind CSS、Radix UIベースのshadcn/ui、Lucideアイコンで実装する。
将来の実行はプロジェクト別の隔離コンテナで状態を保持し、承認済みSkills・MCP・パッケージだけを使う。
未許可の外部送信と破壊的操作は実行前に確認する。既存エージェントも接続候補だが契約と方式は検証して決める。

## 段階別の契約

| 段階                        | 正本                            | 今回の到達点                                              |
| --------------------------- | ------------------------------- | --------------------------------------------------------- |
| ①認証・プロジェクト・画面   | identity / projects / workbench | 実装・テスト対象。実Entra接続は設定後に確認               |
| ②ファイル・チャット・キュー | research-services               | deferred、設計と依存だけ記録                              |
| ③Python/R・Notebook         | notebook-runtime                | deferred、変数はカーネル生存中のみ                        |
| ④Skills/MCP・エージェント   | agent-extensions                | deferred、Mastraの採用をspikeで判断                       |
| ⑤文献・RAG・成果物追跡      | research-evidence               | deferred、文献ライブラリ／PDF注釈／研究パッケージは対象外 |
| ⑥配備・負荷・運用           | platform-operations             | deferred、AKSとオンプレミスKubernetesで検証               |

## 未決事項の扱い

規制対象データ、保存・削除、バックアップ、復旧目標、費用と性能保証は未確定。
削除と共有は①に追加しない。モデルの個人サブスクリプションを共有する設計は採らない。
将来の要件を有効化するときは、TEST ID・受入条件・設計・承認・実装タスクを正本に追加する。
